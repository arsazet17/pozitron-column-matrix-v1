# ПОЗИТРОН · МАТРИЦА СТОЛБОВ v1.0

Отдельное приложение. Не связано с KENO v6.2.2, KENO v7.2 и TOP-3.

## Что делает
- строит матрицу победивших столбов 1–10 по тиражам;
- показывает частоты сверху;
- показывает состояние столба до выхода: 0 / 1 / 2 / 3 / 4+;
- фильтр 30/50/100/200/500 тиражей;
- фильтр по дате;
- автообновление;
- локально сохраняет базу телефона.
